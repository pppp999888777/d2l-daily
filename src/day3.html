第一部分

2.4 微积分

对应原书第 2.4 节

原书说，拟合模型其实是两件事：优化（让模型在训练数据上表现好）和泛化（让它在没见过的数据上也好）。今天讲优化要用的工具。

2.4.1

导数：x 动一点点，y 动多少

函数 f 在 x 处的导数定义为：让 h 趋近于 0 时，(f(x + h) − f(x)) ÷ h 的极限。它是 f 在 x 处的瞬时变化率，也是曲线在这一点切线的斜率。原书用 f(x) = 3x² − 4x 做实验：

令 x = 1，让 h 一次比一次小，算出来的数越来越接近 2：

割线怎么变成切线

绿线连接 x 和 x + h 两个点，叫割线，它的斜率就是上面算的那个数。把 h 往 0 拖，割线慢慢贴住曲线，变成虚线的切线。

用求导法则可以直接算：常数的导数是 0，xⁿ 的导数是 n·xⁿ⁻¹，eˣ 的导数是 eˣ，ln x 的导数是 1/x，再加上常数倍、加法、乘法、除法几条法则。所以 f'(x) = 3·2x − 4 = 6x − 4，x = 1 时正好是 2。

2.4.3

偏导数和梯度

模型的损失通常同时依赖很多个参数。只让其中一个参数动、其他不动时求出的导数叫偏导数。把对每个参数的偏导数排成一个向量，就是梯度，写作 ∇f。梯度指向函数增长最快的方向，所以往梯度的反方向走一小步，函数值下降得最快。这就是梯度下降。

在山坡上找下山的方向

函数是 f(x₁, x₂) = x₁² + 3x₂²，颜色越深越高，最低点在中间。点图上任意位置放一个小球，箭头是负梯度方向。点“走一步”，小球按 位置 ← 位置 − 学习率 × 梯度 往下走。

把学习率调到 0.34 以上，小球会在 x₂ 方向来回越跳越远。第 1 天修水管时学习率太大参数爆炸，也是这个原因。

2.4.4

链式法则

深度学习的函数是一层套一层的。如果 y = f(u)，u = g(x)，那么 dy/dx = dy/du × du/dx：一层一层的导数乘起来。比如 y = (3x + 1)²，令 u = 3x + 1，则 dy/du = 2u，du/dx = 3，所以 dy/dx = 6(3x + 1)。x = 2 时是 42。用数值方法验证：

神经网络有几十上百层，手算每层的导数再乘起来太累了，而且容易出错。PyTorch 会帮你自动按链式法则从最后一层往回乘，这就是第二部分要讲的自动微分，也叫反向传播。
