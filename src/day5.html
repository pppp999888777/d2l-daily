第一部分

3.1 线性回归

对应原书第 3.1 节

线性回归有两个假设：一是输出 y 可以写成输入特征 x 的加权和；二是观测里的噪声比较“正常”，服从正态分布。原书的例子是按房子的面积和房龄估计房价。

3.1.1

线性模型

价格 = w面积 × 面积 + w房龄 × 房龄 + b。w 叫权重，决定每个特征的影响有多大；b 叫偏置，是所有特征都为 0 时的预测值。有 d 个特征时写成点积 ŷ = wᵀx + b。把 n 个样本摞成矩阵 X（每行一个样本，每列一个特征），一次算出所有预测：ŷ = Xw + b，这里加 b 用的是第 1 天学的广播。

拧一拧权重和偏置

表里的 4 套房子是编的示例数据。权重是负数表示这个特征越大价格越低，比如房龄。

3.1.2

损失函数和解析解

回归最常用的损失是平方误差：l = ½(ŷ − y)²。前面乘 ½ 只是为了求导后系数刚好是 1。在整个训练集上取平均，就是要最小化的 L(w, b)。

线性回归比较特殊，最优解可以用一个公式直接算出来，叫解析解：把 b 并进 w（给 X 加一列全 1），w* = (XᵀX)⁻¹Xᵀy。下面用 6 个样本验证：数据是按 w = [2, −3.4]、b = 4.2 造的，解析解正好算回这三个数。

但绝大多数深度学习模型没有解析解，只能一步一步地优化。

3.1.3

小批量随机梯度下降

梯度下降每更新一次都要算整个数据集的梯度，数据一多就太慢。实际做法是每次随机抽一小批样本（叫一个小批量），只用它们算梯度来更新参数，这叫小批量随机梯度下降：

(w, b) ← (w, b) − (η / |B|) · Σi∈B ∂l⁽ⁱ⁾(w, b)

|B| 是每批的样本数，叫批量大小；η 是学习率。这两个是人手动设定、训练中不会更新的参数，叫超参数。所有样本都用过一遍叫一个 epoch（迭代周期）。调超参数要看模型在单独的验证集上的表现。你论文代码里的 BS = 256、15 个 epoch、DKT 的学习率 2e-3，说的就是这些。

批量大小怎么影响下山的路

数据和下面 3.2 节一样：1000 个样本，真实 w = [2, −3.4]，b = 4.2。图上是 w₁、w₂ 两个参数的损失等高线（b 固定在真实值时），叉号是最低点。选不同的批量大小训练，看参数走出的路径。批量越小，每一步越“抖”，但一个 epoch 里更新的次数越多。

训练完的模型拿来估计新房子的价格，叫预测。很多人也叫“推断”，原书提醒在统计学里“推断”指的是估计参数，跟统计学家交流时容易误会。

3.1.5

正态分布与平方损失

正态分布（高斯分布）的概率密度是 p(x) = 1/√(2πσ²) · exp(−(x − μ)²/(2σ²))，μ 是均值，σ 是标准差。

改均值是把曲线左右平移，加大标准差会让曲线变矮变宽。

为什么线性回归用平方损失？假设观测 y = wᵀx + b + ε，噪声 ε 服从均值为 0 的正态分布。那么“看到这批数据的概率”（似然）是每个样本概率的乘积。让似然最大，等价于让负对数似然最小；把正态分布的公式代进去，去掉和 w、b 无关的常数，剩下的正好是平方误差之和。也就是说，在高斯噪声假设下，最小化平方损失就是极大似然估计。你论文的 DKT 预测对错用的交叉熵 BCE，也是这样从“伯努利分布的负对数似然”推出来的，第 6 天学 softmax 时会再讲。

3.1.6

线性回归就是一个单层神经网络

x₁x₂⋮xd输入层（d 个特征）
每条连线是一个权重 wᵢ
o₁输出层（1 个神经元）

每个输入都连到每个输出，这种层叫全连接层（也叫稠密层）。数层数时不算输入层，所以线性回归是 1 层的神经网络。原书也讲了它和生物神经元的相似之处：树突接收输入，按突触权重加权，在细胞核里求和。不过原书提醒，现在深度学习的灵感主要来自数学、统计和计算机科学，就像飞机受鸟启发，但航空工程不靠鸟类学。

3.1.7

练习（原书第 1 题）

有一组数 x₁ … xₙ，找一个常数 b 让 Σ(xᵢ − b)² 最小。对 b 求导并令它等于 0：−2Σ(xᵢ − b) = 0，得到 b = 平均值。验证一下：用平均值时平方和最小，换成别的数都更大。

这和正态分布有什么关系？

如果假设这些数来自均值为 b 的正态分布，b 的极大似然估计就是样本平均值，这和上面 3.1.5 讲的“平方损失 = 高斯噪声下的极大似然”是同一件事。

3.2.3

初始化模型参数、定义模型、损失和优化算法

权重从均值 0、标准差 0.01 的正态分布里随机取，偏置设为 0。两个都要 requires_grad=True，因为要对它们求梯度。

模型：Xw + b。X 是 [批量, 2]，w 是 [2, 1]，结果 [批量, 1]，再广播加上 b。

平方损失。把 y 的形状改成和 y_hat 一样，原因见下面的练习 5。

优化器：在 no_grad 里按梯度更新每个参数，再把梯度清零（第 3 天学的两个要点）。损失是一批样本的总和，所以除以批量大小，让步长不受批量大小影响。

对照你的论文

下面是你论文实验代码 experiment.py 里 train_kt 函数的训练循环（第 1355 到 1364 行，省略了几行记录日志和做检查的代码）。和上面逐行对照：

for ep in range(epochs):                         # for epoch in range(num_epochs)
    model.train(); perm = rng.permutation(tr)    # data_iter 里的 random.shuffle(indices)
    for i in range(0, len(perm), BS):            # 一模一样，BS = 256
        b = perm[i:i + BS]                       # 取出这一批的编号
        loss, _ = batch_loss(model, W, b, cfg, parts=parts)   # l = loss(net(X, w, b), y)
        opt.zero_grad(set_to_none=True); loss.backward()       # 清零梯度 + l.sum().backward()
        nn.utils.clip_grad_norm_(params, 5.0); opt.step()      # 梯度裁剪 + sgd([w, b], ...)

区别只是换了零件：模型从 linreg 换成 LSTM，损失从平方损失换成 BCE（Safe-DFKT-AG 还加了价值项、护栏、方差惩罚和防刷分惩罚），优化器从手写的 sgd 换成 torch.optim.Adam，另外多了一步“梯度裁剪”，防止梯度太大把参数推飞（第 17 天讲循环网络时会学）。

练习（原书）

练习 1：把权重初始化为 0，还能训练吗？改下面的初始化再训练。（对线性回归可以，因为每个权重的梯度都不同；学到多层感知机时会看到，多层网络全部初始化为 0 就会出问题。）

练习 5：为什么 squared_loss 里要 reshape？y_hat 的形状是 (10, 1)，y 的形状是 (10,)。不 reshape 直接相减，广播会把它们扩展成 (10, 10)，不报错，但算出来的是 100 个两两相减的差，损失完全错了：

这是最难发现的一类 bug：程序不报错，只是结果不对。调试时多打印 .shape，就是为了抓这种问题。

练习 6：试试不同的学习率，看损失下降得快还是慢。把 lr 改成 0.001、0.1、1 或 3 试试；太大时损失会变成 nan（发散）。

练习 7：样本数不能被批量大小整除时，data_iter 会怎样？1000 个样本、批量大小 300：

最后一批只有 100 个。因为用了 min(i + batch_size, num_examples)，不会越界。

练习 2：给电压和电流的关系建模，自动微分能用来学参数吗？

能。只要模型是由可求导的运算搭成的（比如欧姆定律 V = I·R，R 是要学的参数），定义平方损失，backward() 就能求出对 R 的梯度，用 SGD 更新。自动微分不关心模型的物理意义，只要计算图里每一步都能求导。

练习 4：计算二阶导数会有什么问题？怎么解决？

二阶导数要对“求导这个过程”再求一次导，计算图会变大，花的时间和内存更多；参数很多时，完整的二阶导数矩阵（海森矩阵）有“参数个数的平方”那么多个数，根本存不下。PyTorch 里求二阶导要在第一次求导时写 create_graph=True。实际中常用只算“海森矩阵乘一个向量”这类近似方法。
