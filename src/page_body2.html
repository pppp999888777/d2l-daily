第一部分

第 1 章 引言：用数据编程

对应原书 1.1 至 1.3 节

书一开始举了个例子：写一个程序，听到“Hey Siri”就回答“是”。麦克风每秒采集约 44000 个数字，谁也写不出“哪些数字组合代表 Hey Siri”的规则。机器学习的做法是反过来：不写规则，写一个带很多“旋钮”的程序，再用一大堆标好答案的录音，自动把旋钮拧到合适的位置。

这些旋钮叫参数。参数拧好以后的程序叫模型。拧旋钮的过程叫训练。这就是书里说的“用数据编程”。

1.1

参数就是旋钮：书里修水管的例子

书里的例子：承包商干了 3 小时收你 350 美元，干了 2 小时收你朋友 250 美元。你猜他的收费方式是“上门费 + 每小时费用”。这里的上门费 b 和每小时费用 w 就是两个参数。先自己拧旋钮试试能不能猜对，再点“训练”让电脑按书里的四步法去找。

书里的训练四步

  1. 从一个参数随机（这里是 0）的模型开始，它什么都不会
  2. 拿一些数据样本（这里是账单）
  3. 调整参数，让模型在这些样本上表现好一点
  4. 重复第 2、3 步，直到满意

勾上第三张账单以后，三个点不在一条直线上，没有任何 b 和 w 能把三张都猜对。这时只能让“误差的平方加起来”尽量小，这个量就是书里说的平方误差损失。真实数据几乎都是这样。

1.2

机器学习的四个组件

书里说，不管什么机器学习问题，都离不开这四样东西。最后一列是你论文里对应的东西，学到后面会越来越清楚。

组件是什么修水管的例子你的论文（DKT）

目标函数给模型打分，通常越小越好，所以也叫损失函数平方误差交叉熵 BCE
优化算法调参数、让损失变小的方法梯度下降Adam（梯度下降的改进版）
1.3

特征有多少个：一张照片就是一串数

书里说：一张 200×200 的彩色照片由 200 × 200 × 3 = 120000 个数组成，3 是红、绿、蓝三个通道。改改尺寸看看。第二部分会学到，这正是一个形状为 (200, 200, 3) 的张量。

1.4

训练集、测试集和过拟合

书里打了个比方：训练集上的成绩像模拟考试，测试集上的成绩像期末考试，模拟考得好不保证期末考得好。模型在训练数据上表现很好、换了新数据就不行，叫过拟合。

下面用一条曲线去拟合 10 个实心点（训练集），再用 10 个空心点（测试集）检验。拖动“模型复杂度”，看训练误差和测试误差怎么变。

次数到 9 时，曲线穿过了全部 10 个训练点，训练误差几乎是 0，但在训练点之间乱扭，测试误差很大，这就是过拟合。次数太低（比如 0 或 1）时两个误差都大，叫欠拟合。书的第 4 章会专门讲这件事。

1.5

这是哪种机器学习问题？

书里把常见问题分成几类。经验法则：问“有多少”的通常是回归，问“是哪一个”的通常是分类，没有标签、让机器自己找规律的是无监督学习，靠试错拿奖励的是强化学习。点选你的答案。

1.6

最可能的答案，不一定是该做的决定

书里的例子：模型说一只蘑菇有 20% 的概率是剧毒的死帽蕈。80% 是安全的，那吃不吃？吃错的代价是送命，扔错的代价只是少吃一只蘑菇。所以要比较的是预期损失 = 每种结果的概率 × 这种结果的代价，再加起来。这和你论文的核心问题是一回事：预测准不等于决策好。

2.6.2

样本空间、事件和随机变量

掷骰子所有可能的结果 {1, 2, 3, 4, 5, 6} 叫样本空间。由一些结果组成的集合叫事件，比如“掷出 5”是 {5}，“掷出奇数”是 {1, 3, 5}。掷出 3 时，“掷出奇数”这个事件就发生了。

概率要满足三条公理（科尔莫戈罗夫 1933 年提出）：任何事件的概率都不是负数；整个样本空间的概率是 1；互不相交的事件，“其中任意一个发生”的概率等于它们各自概率之和。

随机变量是取值有随机性的量，比如骰子点数 X。P(X = 5) 是“X 取 5”的概率。点数这种只能取几个值的叫离散随机变量；身高这种可以取任意小数的叫连续随机变量，“身高正好 1.80 米”的概率是 0，有意义的是“落在 1.79 到 1.81 之间”的概率。

2.6.3

多个随机变量：联合、条件、边际

联合概率 P(A = a, B = b)：两件事同时发生的概率。它一定不大于其中任何一件单独发生的概率。

条件概率 P(B = b | A = a) = P(A = a, B = b) ÷ P(A = a)：已经知道 A = a 发生了，B = b 的概率。

贝叶斯定理：P(A | B) = P(B | A) · P(A) ÷ P(B)。它把“已知原因求结果的概率”翻转成“已知结果求原因的概率”。

边际化：P(B) = Σ_A P(A, B)，把另一个变量的所有可能加起来，消掉它。

独立：A 和 B 互不影响时，P(A, B) = P(A) · P(B)，也就是 P(A | B) = P(A)。比如连续两次掷骰子。灯的开关和房间亮不亮就不独立。

练习 3：B 只依赖 A，C 只依赖 B，P(A, B, C) 能化简吗？

能。P(A, B, C) = P(A) · P(B | A) · P(C | B)。因为知道 B 以后 C 和 A 无关，P(C | A, B) 就简化成 P(C | B)。这种结构叫马尔可夫链。BKT 也是这样：这一步会不会只取决于上一步会不会，学生的答题记录则只取决于这一步会不会。

练习 4：第一种检测更准，为什么不把第一种检测做两次，而要换第二种？

上面的计算假设两次检测在“给定是否感染”时互相独立。同一种检测做两次，误报的原因往往是同一个（比如这个人体内有某种会干扰这种试剂的物质），第一次误报了第二次很可能也误报，两次结果不独立，第二次带来的新信息很少。换一种原理不同的检测，误报更接近独立，才能真正提高确定性。

3.1 线性回归

对应原书第 3.1 节

线性回归有两个假设：一是输出 y 可以写成输入特征 x 的加权和；二是观测里的噪声比较“正常”，服从正态分布。原书的例子是按房子的面积和房龄估计房价。

3.1.1

线性模型

价格 = w面积 × 面积 + w房龄 × 房龄 + b。w 叫权重，决定每个特征的影响有多大；b 叫偏置，是所有特征都为 0 时的预测值。有 d 个特征时写成点积 ŷ = wᵀx + b。把 n 个样本摞成矩阵 X（每行一个样本，每列一个特征），一次算出所有预测：ŷ = Xw + b，这里加 b 用的是第 1 天学的广播。

拧一拧权重和偏置

表里的 4 套房子是编的示例数据。权重是负数表示这个特征越大价格越低，比如房龄。

3.1.2

损失函数和解析解

回归最常用的损失是平方误差：l = ½(ŷ − y)²。前面乘 ½ 只是为了求导后系数刚好是 1。在整个训练集上取平均，就是要最小化的 L(w, b)。

线性回归比较特殊，最优解可以用一个公式直接算出来，叫解析解：把 b 并进 w（给 X 加一列全 1），w* = (XᵀX)⁻¹Xᵀy。下面用 6 个样本验证：数据是按 w = [2, −3.4]、b = 4.2 造的，解析解正好算回这三个数。

但绝大多数深度学习模型没有解析解，只能一步一步地优化。

3.1.3

小批量随机梯度下降

梯度下降每更新一次都要算整个数据集的梯度，数据一多就太慢。实际做法是每次随机抽一小批样本（叫一个小批量），只用它们算梯度来更新参数，这叫小批量随机梯度下降：

(w, b) ← (w, b) − (η / |B|) · Σi∈B ∂l⁽ⁱ⁾(w, b)

|B| 是每批的样本数，叫批量大小；η 是学习率。这两个是人手动设定、训练中不会更新的参数，叫超参数。所有样本都用过一遍叫一个 epoch（迭代周期）。调超参数要看模型在单独的验证集上的表现。你论文代码里的 BS = 256、15 个 epoch、DKT 的学习率 2e-3，说的就是这些。

3.1.5

正态分布与平方损失

正态分布（高斯分布）的概率密度是 p(x) = 1/√(2πσ²) · exp(−(x − μ)²/(2σ²))，μ 是均值，σ 是标准差。

改均值是把曲线左右平移，加大标准差会让曲线变矮变宽。

为什么线性回归用平方损失？假设观测 y = wᵀx + b + ε，噪声 ε 服从均值为 0 的正态分布。那么“看到这批数据的概率”（似然）是每个样本概率的乘积。让似然最大，等价于让负对数似然最小；把正态分布的公式代进去，去掉和 w、b 无关的常数，剩下的正好是平方误差之和。也就是说，在高斯噪声假设下，最小化平方损失就是极大似然估计。你论文的 DKT 预测对错用的交叉熵 BCE，也是这样从“伯努利分布的负对数似然”推出来的，第 6 天学 softmax 时会再讲。

3.1.6

线性回归就是一个单层神经网络

x₁x₂⋮xd输入层（d 个特征）
每条连线是一个权重 wᵢ
o₁输出层（1 个神经元）

每个输入都连到每个输出，这种层叫全连接层（也叫稠密层）。数层数时不算输入层，所以线性回归是 1 层的神经网络。原书也讲了它和生物神经元的相似之处：树突接收输入，按突触权重加权，在细胞核里求和。不过原书提醒，现在深度学习的灵感主要来自数学、统计和计算机科学，就像飞机受鸟启发，但航空工程不靠鸟类学。

3.1.7

练习（原书第 1 题）

有一组数 x₁ … xₙ，找一个常数 b 让 Σ(xᵢ − b)² 最小。对 b 求导并令它等于 0：−2Σ(xᵢ − b) = 0，得到 b = 平均值。验证一下：用平均值时平方和最小，换成别的数都更大。

这和正态分布有什么关系？

如果假设这些数来自均值为 b 的正态分布，b 的极大似然估计就是样本平均值，这和上面 3.1.5 讲的“平方损失 = 高斯噪声下的极大似然”是同一件事。

3.4.1

分类问题和独热编码

回归问“有多少”，分类问“是哪一个”：这封邮件是不是垃圾邮件？这张图是猫、鸡还是狗？原书用一个例子：输入是 2×2 的灰度图，4 个像素就是 4 个特征，类别有猫、鸡、狗三种。

标签怎么表示？直接写成 1、2、3 会让模型以为类别之间有大小顺序（“狗 = 3 比猫 = 1 大”），这通常没有意义。常用的是独热编码：向量长度等于类别数，属于哪类哪一位就是 1，其他是 0。猫 = (1, 0, 0)，鸡 = (0, 1, 0)，狗 = (0, 0, 1)。第 2 天的 get_dummies 做的就是这件事。

3.4.2

网络架构

每个类别要一个输出，每个输出都是 4 个输入的加权和再加偏置。所以有 3×4 = 12 个权重和 3 个偏置。写成矩阵：o = Wx + b，W 是 3×4。三个输出 o₁、o₂、o₃ 叫 logit（未规范化的预测，可以是任何实数）。和线性回归一样，这也是一层全连接层，所以 softmax 回归也是单层神经网络。

全连接层的参数很多：d 个输入、q 个输出就要 d×q 个权重。你论文 DKT 的输出层是 64 个输入、145 个输出（ASSISTments 的技能数），光这一层就有 64×145 + 145 = 9425 个参数。

3.4.3

softmax 运算

logit 不能直接当概率：它们可以是负数，加起来也不等于 1，违反第 4 天学的概率公理。softmax 把它们变成概率：先对每个数求 e 的幂（保证是正数），再除以总和（保证加起来是 1）：

ŷⱼ = exp(oⱼ) / Σₖ exp(oₖ)

它不改变大小顺序，所以预测哪一类时，看 logit 最大的那个就行。softmax 回归虽然用了非线性的 softmax，但输出仍由输入的仿射变换决定，所以它还是线性模型。

softmax 调试台

拖动三个类别的 logit，看概率怎么变。选一个“真实类别”，下面会算出交叉熵损失和它对 logit 的梯度。“温度”是把 logit 先除以一个数再做 softmax：温度低，最大的那个更突出；温度高，概率更平均。调试台第 5 章生成文字时也有这个温度。

3.4.4

小批量的矢量化

一个小批量 X 的形状是 [n, d]（n 个样本，d 个特征），权重 W 是 [d, q]，偏置 b 是 [1, q]，q 是类别数。O = XW + b，Ŷ = softmax(O)，O 和 Ŷ 都是 [n, q]。softmax 按行做：每一行是一个样本，每行的 q 个数变成这个样本属于各类的概率。

3.4.5

3.4.7

信息论基础：熵和惊异

原书从信息论的角度解释交叉熵。一个结果发生的概率是 P，看到它时的惊异是 −log P：越罕见的事越让人惊讶。熵 H(P) = Σ −P(j) log P(j) 是平均惊异，衡量一个分布有多“不确定”。用以 2 为底的对数，单位是比特。四个结果完全平均时熵最大，是 2 比特；越集中熵越小：

交叉熵 H(P, Q) = Σ −P(j) log Q(j)：真实分布是 P，你却按自己以为的分布 Q 去预期，得到的平均惊异。当 Q = P 时最小，就等于熵。所以最小化交叉熵，就是让模型的预测分布 Q 尽量接近数据的真实分布 P。上面的交叉熵损失是它在“真实分布是独热向量”时的特例。

3.4.8

校准：模型说 70%，是不是真有 70%

原书在讲 softmax 时提到一个性质：在模型输出 0.5 的所有样本里，应该刚好有一半真的属于那一类。这叫校准（calibration）。衡量校准的常用指标是 ECE（期望校准误差）：把预测按置信度分成 10 个区间，每个区间里比较“平均预测概率”和“实际正确率”的差，再按样本数加权平均。你论文表 1 里的 ECE（Safe-DFKT-AG 1.21%，DKT 0.94%）就是这样算的，用的正是 10 个等宽区间。

重新审视 softmax 的实现：数值稳定

上面看到，按定义算 softmax，exp 可能上溢成 inf。先减去每行的最大值 max(o) 就不会：分子分母同乘 exp(−max) 结果不变，而最大的那个数变成 exp(0) = 1。但减完以后，很小的数 exp 出来可能下溢成 0，log(0) 又是 −inf。办法是把 softmax 和 log 合在一起：log ŷⱼ = (oⱼ − max) − log Σ exp(oₖ − max)，完全不用算出 ŷ 本身。这叫 LogSumExp 技巧。nn.CrossEntropyLoss 就是这样做的，所以要直接把 logit（未经 softmax 的输出）传给它。你论文的代码就是这样写的：experiment.py 第 1255 行用 F.binary_cross_entropy_with_logits(logit, y, ...)，直接把 logit 传进去，而不是先做 sigmoid 再算 BCE。

4.1.1

线性模型会在哪里出错

线性意味着单调：某个特征变大，输出就一直变大（或一直变小）。原书举了几个例子：

收入越高越可能还贷，这是单调的，但不是线性的：收入从 0 涨到 5 万，比从 100 万涨到 105 万影响大得多。这种可以先对收入取对数再用线性模型。体温和死亡风险连单调都不是：高于 37 度越高越危险，低于 37 度越低越危险。这种可以改用“离 37 度多远”做特征。

可是判断一张图是猫还是狗呢？第 (13, 17) 个像素变亮，是更像猫还是更像狗？这取决于它周围的像素是什么，没法靠给单个像素一个固定权重来判断，也想不出什么简单的预处理能解决。所以要让模型自己学出一种表示，再在这个表示上做线性预测。隐藏层就是干这个的。

4.1.2

隐藏层，以及为什么一定要激活函数

x₁x₂x₃x₄输入层（4）
全连接，权重 W⁽¹⁾ [4, 5]
h₁h₂h₃h₄h₅隐藏层（5）+ 激活函数
全连接，权重 W⁽²⁾ [5, 3]
o₁o₂o₃输出层（3）

这是原书的例子：4 个输入、5 个隐藏单元、3 个输出。输入层不做计算，所以这是一个 2 层的网络，两层都是全连接层。写成矩阵：H = X W⁽¹⁾ + b⁽¹⁾，O = H W⁽²⁾ + b⁽²⁾。

但是这样加一层没有任何用处：线性函数套线性函数还是线性函数。把两层合并，W = W⁽¹⁾W⁽²⁾、b = b⁽¹⁾W⁽²⁾ + b⁽²⁾，就是一个等价的单层模型。用数字验证一下：

关键在于给隐藏层的每个单元套一个非线性的激活函数 σ：H = σ(X W⁽¹⁾ + b⁽¹⁾)。有了它，多层就没法合并成一层了。再多叠几层，H⁽¹⁾ = σ(XW⁽¹⁾ + b⁽¹⁾)，H⁽²⁾ = σ(H⁽¹⁾W⁽²⁾ + b⁽²⁾)……模型就能表示越来越复杂的函数。

理论上，只要隐藏单元足够多，单隐藏层的 MLP 能以任意精度逼近任何连续函数，这叫通用近似定理。但原书提醒：能表示不代表容易学到，实际中用更深而不是更宽的网络往往效果更好。

用 ReLU 拼出一条曲线

每个隐藏单元算 ReLU(x − kᵢ)，是一条在 kᵢ 处折一下的折线。输出层把它们加权求和，就拼出一条折线去逼近蓝色的目标曲线。权重用最小二乘直接求出。增加隐藏单元，看折线怎么越来越贴近。浅色线是每个隐藏单元乘上权重后的贡献。

4.1.3

激活函数

ReLU（修正线性单元）最常用：ReLU(x) = max(x, 0)，负数变 0，正数不变。它的导数在 x > 0 时是 1，x < 0 时是 0。梯度要么原样通过，要么被挡住，所以不容易出现梯度消失，训练表现好。

用第 3 天学的自动微分画出导数。y 是向量，所以 backward 要传一个全 1 的梯度（等价于对 y.sum() 求导）；retain_graph=True 保留计算图，后面还要用。

sigmoid 把任何实数压到 (0, 1)：sigmoid(x) = 1 / (1 + e⁻ˣ)。它曾经是隐藏层的标准选择，现在多用在输出层表示概率，比如第 6 天的二元分类，以及你论文里 DKT 输出“答对的概率”。

sigmoid 的导数是 sigmoid(x)(1 − sigmoid(x))，最大只有 0.25（在 x = 0 处），x 离 0 远时几乎是 0。很多层都用 sigmoid 时，梯度一层层乘下去会越来越小，这就是梯度消失，第 10 天会细讲。

tanh（双曲正切）把输入压到 (−1, 1)，形状像 sigmoid，但关于原点对称。导数是 1 − tanh²(x)，最大是 1。LSTM 内部就用 tanh 和 sigmoid（第 14 天）。

4.4 模型选择、欠拟合和过拟合

对应原书第 4.4 节
4.4.1

训练误差和泛化误差

训练误差是模型在训练集上的误差；泛化误差是模型在无穷多同分布新数据上的期望误差，只能用一个独立的测试集去估计。原书举了个例子：一个学生把往年考题的答案全背下来，往年题全对，但遇到新题就不会了。这就是只降低了训练误差，泛化误差没降。

这一切有个前提：训练数据和测试数据是从同一个分布里独立抽出来的（独立同分布，i.i.d.）。这个假设不成立时会发生什么，是第 10 天“分布偏移”的内容，也是你论文“模拟器和真实日志不一样”这个问题的根源。

影响模型能不能泛化的因素有：可调参数的数量（自由度）、参数能取的值的范围、训练样本的数量。参数越多、取值越自由、样本越少，越容易过拟合。

4.4.2

模型选择和验证集

选模型（比如隐藏层要几层、学习率多大）时，绝对不能看测试集，否则测试集就被用来“训练”了，它的结果不再是公正的估计。正确做法是从训练数据里再分出一块验证集，用它来比较和挑选。训练数据很少时，可以用 K 折交叉验证：把训练数据分成 K 份，轮流用 1 份验证、K − 1 份训练，最后取平均。

4.4.3

多项式回归实验

原书用一个实验同时演示正常拟合、欠拟合和过拟合。数据按一个 3 阶多项式生成：y = 5 + 1.2x − 3.4x²/2! + 5.6x³/3! + 噪声。然后分别用 3 阶（刚好）、1 阶（太简单）、19 阶（太复杂）的多项式去拟合，训练集只有 100 个样本。除以阶乘是为了不让高次项的数值太大。

评估函数：在整个数据集上算平均损失。

正常拟合：用 3 阶多项式（前 4 个特征：1、x、x²/2!、x³/3!）。学到的权重应该接近真实的 [5, 1.2, −3.4, 5.6]，训练损失和测试损失都很低，而且差不多大。

欠拟合：只用 1 阶（一条直线）。模型太简单，训练损失也降不下去，两条曲线都停在高处。

过拟合：用全部 20 个特征（19 阶）。模型太复杂，会去拟合训练数据里的噪声。训练损失一直下降，测试损失却降不下去，两条线拉开了距离。学到的高次项权重也不再是 0。

4.5 权重衰减

对应原书第 4.5 节，代码来自原书 PyTorch 版

多收集数据最能缓解过拟合，但数据往往有限。另一个办法是限制模型的“自由度”。权重衰减（也叫 L2 正则化）在损失里加一项 (λ/2)‖w‖²，权重越大惩罚越大，逼着模型用尽量小的权重去拟合数据。λ 越大，约束越强。

为什么叫“衰减”？对 L + (λ/2)‖w‖² 求梯度，多出来的一项是 λw。代进梯度下降：w ← w − η(∂L/∂w + λw) = (1 − ηλ)w − η∂L/∂w。每一步先把权重乘一个略小于 1 的数，相当于让它“衰减”一点，再按原来的梯度走。为什么用 L2 而不是 L1？L2 对大权重惩罚更重，倾向于把权重均匀地分散到很多特征上；L1 会把很多权重压成正好 0，相当于做特征选择。

λ 怎么把最优解拉向原点

椭圆是不加惩罚时损失的等高线，叉号是不加惩罚的最优解。橙点是加了 (λ/2)‖w‖² 以后的最优解，灰色曲线是 λ 从 0 增大时橙点走过的路。λ 越大，橙点越靠近原点，权重越小。

原书的实验故意让过拟合很严重：200 个特征，但只有 20 个训练样本。真实的 w 每个都是 0.01，b = 0.05。

不加惩罚（λ = 0）：训练损失一路降，测试损失居高不下，严重过拟合。

加上惩罚（λ = 3）：训练损失高了一点，但测试损失明显下降，w 的范数也小得多。

简洁实现：PyTorch 的优化器自带 weight_decay 参数。这里用了“参数组”的写法：只对权重衰减，偏置不衰减。

对照你的论文：只给策略头加 L2

Safe-DFKT-AG 的损失里有一项 ρ‖θ_g‖²（ρ = 10⁻³），只惩罚策略头 g 的参数，限制它推翻“最接近 0.7”规则的力度。代码在 experiment.py 第 1272 到 1273 行，和上面的 l2_penalty 是同一个东西，只是没有除以 2，而且只对 model.g 的参数求和：

4.6 暂退法（Dropout）

对应原书第 4.6 节，代码来自原书 PyTorch 版

好的模型应该对输入的小扰动不敏感。暂退法的做法是：训练时每次前向传播，随机把一部分隐藏单元的输出置成 0（概率为 p），剩下的除以 (1 − p) 放大。这样每个单元的期望值不变：E[h′] = (1 − p)·h/(1 − p) = h。网络没法依赖某几个特定的单元，只能学出更“分散”、更稳健的表示。测试时不丢弃，所有单元都用上。

看一次 Dropout 丢掉了谁

每个格子是一个隐藏单元的输出（数值写在格子里）。灰色的被丢掉了，剩下的被放大了 1/(1 − p) 倍。多采样几次，看平均值是不是还接近原来的值。

两个隐藏层的网络，每层 256 个单元。原书建议靠近输入层的丢弃概率小一些（第一层 0.2），后面大一些（第二层 0.5）。self.training 标记现在是训练还是评估。

训练。和原书的不同：原书批量 256；本页只有 6000 张训练图，批量 256 时训练损失卡在 0.65 附近，时过时不过 train_ch3 的检查（我在真 PyTorch 上试过），所以改成 64。

简洁实现：在全连接层后面加 nn.Dropout(p)。调用 net.train() 时 Dropout 生效，调用 net.eval() 时 Dropout 什么也不做。d2l.train_ch3 里训练前会调 net.train()，评估前会调 net.eval()。

梯度消失和梯度爆炸

一个 L 层的网络，第 l 层算 h⁽ˡ⁾ = f_l(h⁽ˡ⁻¹⁾)。按链式法则，损失对第 l 层参数的梯度是 L − l 个矩阵连乘再乘一个向量：

∂o/∂W⁽ˡ⁾ = M⁽ᴸ⁾ · M⁽ᴸ⁻¹⁾ ⋯ M⁽ˡ⁺¹⁾ · v⁽ˡ⁾，其中 M⁽ᵏ⁾ = ∂h⁽ᵏ⁾/∂h⁽ᵏ⁻¹⁾

很多个数连乘，结果要么越来越小（梯度消失，前面的层几乎学不动），要么越来越大（梯度爆炸，参数一步就飞出去）。这和 0.9¹⁰⁰ ≈ 0.00003、1.1¹⁰⁰ ≈ 13781 是一个道理。

4.8.2

参数初始化

不指定的话，PyTorch 会给每种层一个默认初始化，中等规模的问题一般够用。Xavier 初始化的想法是：让每一层输出的方差和输入的方差一样，信号就不会一层层放大或缩小。

考虑一个没有激活函数的全连接层 o_i = Σⱼ w_ij·x_j，输入有 n_in 个，输出有 n_out 个。设权重均值 0、方差 σ²，输入均值 0、方差 γ²，且相互独立。那么：

Var[o_i] = Σⱼ E[w²_ij]·E[x²_j] = n_in · σ² · γ²

要让 Var[o_i] = γ²，需要 n_in·σ² = 1。反向传播时同样的推导给出 n_out·σ² = 1。两个条件没法同时满足，Xavier 取折中：

σ² = 2 / (n_in + n_out)

如果用均匀分布 U(−a, a)，它的方差是 a²/3。令 a²/3 = 2/(n_in + n_out)，得到 a = √(6 / (n_in + n_out))。

实验：10 层、每层 256 个单元、ReLU 激活。权重乘 0.01 时信号几乎消失；按 He 初始化（σ² = 2/n_in，专门为 ReLU 设计，补偿 ReLU 砍掉一半的方差）时，信号的大小保持住了。

信号穿过 L 层

一个每层 64 个单元的网络，输入 64 个样本。实线是每一层输出的标准差（前向信号），虚线是损失对每一层权重的梯度大小（反向信号）。纵轴是对数刻度，每一格差 10 倍。两条线都保持水平，才说明信号既没有消失也没有爆炸。

4.9.1

三种分布偏移

训练数据来自分布 p_S(x, y)（源分布），模型上线后遇到的数据来自 p_T(x, y)（目标分布）。两者不一样时，按训练集挑出来的最好的模型，上线后不一定好。原书分三种情况：

  • 协变量偏移：输入的分布变了，p(x) 不同，但“给定输入，标签怎么来”没变，p(y | x) 相同。例子：用真实照片训练猫狗分类器，上线后要分类卡通图片。
  • 标签偏移：标签的分布变了，p(y) 不同，但 p(x | y) 没变。例子：用夏天的病例训练诊断模型，冬天流感病人的比例大增。
  • 概念偏移：标签本身的定义变了，p(y | x) 不同。例子：同一种饮料，在美国不同地区叫 soda、pop 或 coke。

原书还提醒了一种更麻烦的情况：模型自己的决策会改变以后的数据。比如贷款模型拒绝了某类人，以后就再也看不到这类人还不还款的数据了。

对照你的论文：这正是 OPE 要解决的问题

你论文的真实日志是在原来的出题策略 μ 下收集的：学生做了哪些题、按什么顺序做，都由 μ 决定。你训练的新策略 π 会选不同的题，于是学生遇到的“状态和题目”的分布就变了。这是原书说的“模型的决策改变了数据”，也是一种协变量偏移。直接拿日志里的平均奖励当新策略的成绩是有偏的，所以论文用离线策略评估（OPE）给每条记录加权重 π(a | s) / μ(a | s)。下面就来看这种权重是怎么来的。

4.9.3

协变量偏移纠正：重要性加权

我们真正想最小化的是目标分布上的风险 E_{x∼p_T}[l(f(x), y)]，但手里只有源分布的样本。因为 p(y | x) 没变，可以把目标分布的期望改写成源分布的期望：

E_{p_T}[l] = E_{p_S}[ β(x) · l ]，其中 β(x) = p_T(x) / p_S(x)

也就是说，给每个训练样本乘一个权重 β(xᵢ)：在目标分布里更常见的样本权重大，更少见的权重小。这就是重要性加权。

β 怎么来？原书给了一个巧妙的办法：训练一个分类器区分“这个 x 来自源分布还是目标分布”（目标记为 1）。两边样本一样多时，分类器输出的对数几率 h(x) 正好估计了 log(p_T(x)/p_S(x))，所以 β(x) = exp(h(x))。

拖动目标分布，看加权有没有用

真实规律是抛物线 y = x²/2（灰线）。蓝点是训练样本（源分布），橙色区域是上线后会遇到的 x（目标分布）。模型只是一条直线。不加权的直线（虚线）在源分布那块拟合得最好；按 β = p_T/p_S 加权后的直线（实线）会照顾目标分布那块。

用 PyTorch 做一遍：源分布中心在 −0.5，目标分布中心在 1.0。
