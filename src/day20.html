代码地图

行号对应你论文项目 code/experiment.py 的当前版本

614–644NLG 步收益和收益表第 19 天

step_rewards 给每一步算一个收益：做这道题之前，这个知识点的平滑正确率是 pre；之后在同一知识点上接下来最多两次的平均正确率是 post。收益是归一化增益：post ≥ pre 时 (post − pre)/(1 − pre)，否则 (post − pre)/pre，截到 [−1, 1]。qtab 把每个知识点的平均收益做成 Q 表（OPE 里 DM 用的结果模型）。下面第二部分可以直接运行这个函数。

1248–1299batch_loss：Safe-DFKT 的损失第 9、14、19 天

loss = bce                                                  # 所有模型都有的预测损失（第 14 天）
if cfg is not None:                                         # 下面只有决策导向的方法才有
    p = torch.sigmoid(model.readout_all(H, qpos))
    score = -(p - cfg.get("c", C_TARGET)) ** 2 / TEMP + model.policy_bias(H, qpos)
    pi = torch.softmax(score, -1)                           # 可求导的出题策略
    loss += cfg["ag_eta"] * agm                             # 反刷分：别把概率放在已掌握的知识点上
    loss += cfg["head_l2"] * sum((q ** 2).sum() for q in model.g.parameters())   # 第 9 天
    V = dm + w * (r - qa)                                   # 每一步的 DR 价值（第 19 天）
    loss += -cfg["lam"] * Vs.mean()                         # 最小化损失 = 最大化 DR 价值
    loss += cfg["beta"] * Vs.var()                          # POEM：惩罚价值估计的方差

上面是节选，省略了 if 判断和中间变量的计算（完整代码见第 1248 到 1299 行）。这是整篇论文的核心。前 19 天的东西全在这里：BCE、softmax 策略、gather、截断的重要性权重、DR、L2。安全屏障的意思是：BCE 只要不比原始 DKT（bce_base）差超过 0.5%，这一项就是 0；一旦超过，就以系数 10 拉回来。所以 Safe-DFKT 在提高出题价值的同时，预测能力几乎不变。

1

NLG 步收益（原样照抄第 614 行）

一个学生 7 步：知识点 [0, 1, 0, 0, 1, 2, 0]，对错 [0, 0, 1, 1, 0, 1, 1]，三个知识点的总体正确率（平滑用）是 [0.5, 0.7, 0.4]。

逐个看：第 1 步做知识点 0（错），之前没做过，pre = (0 + 2×0.5)/(0 + 2) = 0.5；之后两次知识点 0 都对，post = 1，收益 (1 − 0.5)/(1 − 0.5) = 1。第 2 步做知识点 1（错），pre = 0.7；下一次知识点 1 还是错，post = 0，收益 (0 − 0.7)/0.7 = −1。最后出现的几步后面没有同知识点的题了，收益没有定义（mn = 0），训练时被掩码掉。

2

决策损失的缩小版

2 个学生、5 步、3 个知识点。策略头 g 初始化为 0，所以一开始策略就是“选最接近 0.7 的”。算出 DR 价值和整个损失，反向传播，看 g 的梯度：

第 1 个学生的预测是 [0.9, 0.6, 0.3]，知识点 1（0.6）离 0.7 最近，所以 π 给它 0.63。g 的梯度对知识点 1 是负的：梯度下降会让 g 在知识点 1 上变大，也就是让策略更倾向知识点 1。原因是日志里这一步出的正是知识点 1，收益 0.4 比 Q 表的平均值 0.3 高，DR 认为“多选它更好”。这就是“决策导向”的意思：用出题的价值，而不只是预测准确率，去训练模型。
