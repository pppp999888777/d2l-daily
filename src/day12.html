8.1 序列模型

对应原书第 8.1 节，代码来自原书 PyTorch 版
8.1.1

统计工具

序列 x₁, x₂, …, x_T 的联合概率可以按时间顺序拆开：P(x₁, …, x_T) = ∏ₜ P(xₜ | x_{t−1}, …, x₁)。所以只要会“根据过去预测下一个”，就能处理整个序列。难点是过去越来越长，有两种办法：

  • 自回归模型：只看最近 τ 个，xₜ ≈ f(x_{t−1}, …, x_{t−τ})。参数个数固定。只看最近 τ 个就够的假设叫马尔可夫条件。
  • 隐变量自回归模型：用一个“摘要” hₜ 记住过去的信息，每一步更新它：hₜ = g(h_{t−1}, x_{t−1})，再用它预测 x̂ₜ = P(xₜ | hₜ)。

对照你的论文：KT 模型就是这两类

你论文里的基线正好分属这两类。BKT 是隐变量模型，隐变量是“学生会不会这个知识点”（只有会和不会两个状态），每做一道题按贝叶斯公式更新一次（第 4 天学过）。DKT 也是隐变量模型，隐状态是 LSTM 的 64 维向量 h，由神经网络学出来怎么更新。LR、PFA 这类计数模型则只用“这个知识点答对过几次、答错过几次”这样的统计量，不维护隐状态。

预测

单步预测：每次都用真实的前 4 个点预测下一个，效果很好。

多步预测：604 步以后不再给真实数据，用自己的预测当输入继续往后预测。误差会一步步累积，很快就偏到一条平线上去了。

系统地看一下 k 步预测：k 越大，越偏离真实曲线。

对照你的论文：模拟器的多步推演

你论文用模拟学生评估出题策略：策略出一道题，模拟器给出对错，再出下一道……一直推演很多步。这就是多步预测，误差也会累积，所以论文要单独检查模拟器和真实日志差多少（模拟 AUC、模拟 ECE 那几列）。而 KT 模型训练时用的是真实日志，每一步都拿真实的历史去预测下一题，相当于单步预测。

for st in range(0, L, win):          # L 是这个学生的记录条数，win = 100
    e = min(L, st + win)
    if e - st >= 2:
        rows.append((i, st, e))       # 第 i 个学生，从 st 到 e

对应原书第 8.4 节，代码来自原书 PyTorch 版
8.4.2

有隐状态的循环神经网络

第 8 天的多层感知机：H = φ(X W_xh + b_h)，输出 O = H W_hq + b_q。RNN 多了一项：上一步的隐状态也参与计算。

Hₜ = φ(Xₜ W_xh + H_{t−1} W_hh + b_h)
Oₜ = Hₜ W_hq + b_q

形状：批量 n、输入 d 维、隐藏 h 维、输出 q 维时，Xₜ 是 (n, d)，Hₜ 是 (n, h)，W_xh 是 (d, h)，W_hh 是 (h, h)，W_hq 是 (h, q)。每个时间步用的是同一组参数，所以序列再长，参数个数也不变。H_{t−1} W_hh 这一项就是“记忆”：上一步的信息通过它传到这一步。

Xₜ W_xh + H_{t−1} W_hh 可以写成一次矩阵乘法：把 Xₜ 和 H_{t−1} 横着拼起来，W_xh 和 W_hh 竖着拼起来。验证一下：

只有 1 个知识点、隐状态 2 维的 RNN，权重是手动设的。输入 xₜ：答对是 +1，答错是 −1。隐状态 hₜ = tanh(xₜ·w_x + h_{t−1}·W_hh + b)，预测下一题答对的概率 p = sigmoid(h·w_q + b_q)。点格子切换对错，看隐状态（两条线）和预测概率（柱子）怎么变。

8.4.4

困惑度

怎么衡量语言模型好不好？用每个词元的平均交叉熵：(1/n) Σ −log P(xₜ | x_{t−1}, …, x₁)。原书用它的指数，叫困惑度（perplexity）：

困惑度 = exp( −(1/n) Σₜ log P(xₜ | x_{t−1}, …, x₁) )

可以理解成“模型平均在几个选项里犹豫”。完美模型每次都给正确答案概率 1，困惑度是 1；完全瞎猜（词表 28 个字符、每个概率 1/28），困惑度是 28；模型越差，困惑度越大。

对照你的论文：BCE 和困惑度

KT 预测的是“对或错”两个选项，平均交叉熵就是论文里的 BCE（验证集上用它挑检查点）。BCE 的指数就是二选一的困惑度：瞎猜（每次都说 0.5）时 BCE = log 2 ≈ 0.693，困惑度正好是 2。你论文结果文件 results.json 里记录的 DKT 训练曲线（5 个随机种子），验证集 BCE 最低在 0.556 到 0.560 之间，困惑度约 1.75。比瞎猜好，但离 1 还远：学生答题本来就有很大的随机性。
