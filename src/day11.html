自定义块

自己写一个块，只要做两件事：在 __init__ 里创建要用的层（先调用 super().__init__()），在 forward 里写怎么从输入算到输出。反向传播不用写，自动求导会处理。

5.1.2

顺序块

自己实现一个 Sequential：把传进来的块按顺序存进 _modules（一个有序字典），前向传播时依次调用。存进 _modules 的块，PyTorch 才知道它们的参数要一起训练。

你论文 experiment.py 第 1012 行先定义了一个所有 KT 模型共用的父类，第 1032 行的 DKT 再继承它：

class KTBase(nn.Module):
    def __init__(self, K):
        super().__init__()
        self.K = K                        # 知识点个数，普通属性，不是参数

class DKT(KTBase):
    def __init__(self, K, d=D_MODEL, policy_head=False):     # D_MODEL = 64
        super().__init__(K)               # 调用 KTBase.__init__，它再调用 nn.Module.__init__
        self.emb = nn.Embedding(2 * K, d); self.lstm = nn.LSTM(d, d, batch_first=True)
        self.drop = nn.Dropout(0.2); self.out = nn.Linear(d, K)
        self.is_df = policy_head
        if policy_head:                   # 只有 Safe-DFKT 系列才有策略头
            self.g = nn.Linear(d, K)
            nn.init.zeros_(self.g.weight); nn.init.zeros_(self.g.bias)

    def encode(self, sk, rs):
        x = self.emb(sk + self.K * rs.long()); h, _ = self.lstm(x)
        return {"h": self.drop(h), "B": sk.shape[0]}

注意两点。第一，if policy_head: 是在 __init__ 里根据参数决定要不要创建一层，同一个类能造出两种模型（这也是 5.1.3 说的“块里可以写任何 Python 代码”）。第二，这个类没有写 forward，而是写了 encode、readout 这些自己起名的方法，训练代码直接调用 model.encode(...)。这样做是可以的：forward 只在你写 model(x) 时才被用到。要是对这个类写 model(x)，就会报下面这种错：

补充

在内存里存检查点：为什么要 clone()

你论文没有把检查点写到硬盘，而是存在内存里的一个字典。这里有个坑：state_dict() 返回的张量和模型参数共用同一块内存。不 clone() 的话，以后参数一更新，“存下来的最佳参数”也跟着变了。
