11.6 动量法

对应原书第 11.6 节，代码来自原书 PyTorch 版

函数 f(x) = 0.1x₁² + 2x₂² 在 x₂ 方向很陡、x₁ 方向很平。学习率小时，x₁ 方向走得极慢；学习率稍大，x₂ 方向就来回震荡甚至发散：

动量法：不直接用当前梯度，而是用梯度的“滑动和”作为速度：

vₜ = β v_{t−1} + gₜ
xₜ = x_{t−1} − η vₜ

在 x₂ 方向，梯度正负交替，加起来互相抵消，震荡变小；在 x₁ 方向，梯度一直同号，越积越大，走得更快。

vₜ 展开是 Σ_τ β^τ g_{t−τ}：过去梯度的加权和，越久以前的权重越小。β 越大，记得越久：

第四部分

11.10 Adam

对应原书第 11.10 节，代码来自原书 PyTorch 版

Adam 同时维护两个滑动平均：梯度的（一阶矩，相当于动量）和梯度平方的（二阶矩，衡量这个参数的梯度通常有多大）：

vₜ = β₁ v_{t−1} + (1 − β₁) gₜ
sₜ = β₂ s_{t−1} + (1 − β₂) gₜ²

两个滑动平均从 0 开始，前几步会偏小，所以要做偏差修正：v̂ = v / (1 − β₁ᵗ)，ŝ = s / (1 − β₂ᵗ)。更新：

x ← x − η · v̂ / (√ŝ + ε)

关键在除以 √ŝ：梯度一直很大的参数，步子被缩小；梯度一直很小的参数，步子被放大。每个参数自动有自己的步长，所以 Adam 对学习率没那么敏感。常用 β₁ = 0.9，β₂ = 0.999。

原书还介绍了 Yogi：把 sₜ 的更新改成 sₜ = s_{t−1} + (1 − β₂) gₜ² ⊙ sign(gₜ² − s_{t−1})，避免梯度突然变大时 s 增长过快。
